# AWS_workshop — College ERP Demo

A responsive front-end mockup of a college ERP/student portal built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and dashboard
- `style.css` — responsive styling
- `script.js` — navigation and demo interactions

## Run it
1. Extract the `AWS_workshop` folder.
2. Open `index.html` in a browser.
3. Click the sidebar items to switch between dashboard sections.

## Important
This is a fictional demo with sample data. It is not connected to a real college ERP, database, student account, attendance system, or payment gateway. Replace the sample content and branding only when you have permission to use the relevant college design/assets.
